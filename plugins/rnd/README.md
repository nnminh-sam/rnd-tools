# RnD plugin

Precise, low-cost toolkit for R&D work on Word, Excel, PowerPoint and PDF files in Claude Code.

Start with `/rnd:setup` in a project folder, or `/rnd:tutorial` for the KESTREL demo.
`/rnd:help` lists every command. Requires [uv](https://docs.astral.sh/uv/).

Full documentation: the repository README and `docs/` folder.
