# KESTREL demo workspace

A synthetic R&D project for learning the RnD toolset: Aldermoor Furniture Co. is developing **KESTREL**, a compact ergonomic task chair for small home offices. The prototype P2 has just been tested and the team must decide how to fix a failed armrest bracket while hitting cost and recycled-content targets.

All companies, people and figures are fictional.

| Folder | What is inside |
|---|---|
| `sources/meetings` | Kickoff notes (targets), weekly sync (Word) |
| `sources/customers` | 12 interview write-ups (Word), survey with 240 responses (Excel) |
| `sources/competitors` | Benchmark of 8 competitor chairs (Excel) |
| `sources/engineering` | Shell material fatigue tests (Excel), P2 test report (PDF) |
| `sources/suppliers` | Supplier quotes / BOM with options A, B, C (Excel) |
| `sources/design` | P2 design review deck (PowerPoint) |
| `sources/market` | Market brief (PDF) |
| `notes` | Designer's idea backlog (Markdown) |
| `outputs` | Where RnD writes reports, decks and spreadsheets |

Start with `TUTORIAL.md`, or run `/rnd:tutorial` in Claude Code.
